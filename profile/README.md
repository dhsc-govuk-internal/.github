# Welcome to the DHSC Internal GitHub!

This organisation hosts internal code and analytical projects produced by the Analysis and Data Science community within the Department of Health and Social Care.

For guidance on setting up Git and GitHub, including how to get access to this GitHub organisation, please see:  
Data Science Front Door > Data Platforms and Software > Software Installation and Tooling > Git Installation Guide

## Migration from [DataS-DHSC](https://github.com/DataS-DHSC/)

Please note that we are currently in the progress of migrating from our old GitHub organisation [DataS-DHSC](https://github.com/DataS-DHSC/) to this new official GitHub organisation [dhsc-govuk-internal](https://github.com/dhsc-govuk-internal/) and that the DataS-DHSC organisation will eventually be archived as read-only.

You should have already received an invitation to the new organisation but if not, or you have any other issues, please contact our GitHub admins at [GitHub@dhsc.gov.uk](mailto:GitHub@dhsc.gov.uk).

We strongly recommend that any new project(s) are started in the new organisation and that you begin planning how best to migrate any existing active project(s) across. Details on how to set up a new project or migrate an existing one can be found in our new [GitHub userguide](https://crispy-adventure-qzrklvk.pages.github.io/) (you will need to be a member of the new organisation to access this guide).
